## Exclusions

This evidence does not incorporate SPINE 1.4, a wholesale upstream-dev merge,
or any non-public specification. It excludes every other hunk in
`9970150f6d81ffa06605fecddedcdf0e38174543`, including key-tag and
update-engine changes.

The cited repository is public upstream implementation evidence. It is not an
independent normative-conformance source and does not establish a SPINE
standard requirement by itself.

## Falsification Criteria

The provenance record is false if a cited public URL no longer resolves to the
named commit and repository, or its relevant diff does not contain the
bounded model correction stated here. It is also false if either version-binding
file at a cited revision does not state SPINE 1.3 / `1.3.0`. A public source
proving that an excluded SPINE 1.4, wholesale-merge, or 9970150
key-tag/update-engine change is needed for the candidate would falsify the
candidate's bounded scope.
