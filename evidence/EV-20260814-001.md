# Entity-Scoped SPINE Use-Case Claims

- Evidence id: `EV-20260814-001`
- Evidence class: `observed_runtime`
- Capture date: 2026-08-14
- Device family: redacted SHIP HVAC gateway
- Add-on version: `0.6.43`
- Gateway source:
  [`helianthus-ebusgateway` pull request 810](https://github.com/Project-Helianthus/helianthus-ebusgateway/pull/810)
- Acquisition method: owner-authorized raw MCP topology read followed by the
  authenticated Portal SPINE root read against the same running gateway
- Artifact class: `shareable_redacted`
- Private artifact retained: yes
- Publication status: publishable

## Observed Canonical Shape

The owner-only raw topology was valid and reported one remote device, eleven
entities, twenty features, and twenty-two use-case claims. Every observed
claim's canonical `context_address` exactly equalled one of the eleven entity
addresses. None equalled a feature address. The claim payloads remained valid
raw-snapshot members and the raw MCP topology returned no contract error.

The authenticated Portal SPINE root returned the categorical
`admin_boundary_unavailable` response and no partial tree. Inspection against
the reviewed gateway source isolated the mismatch: the lazy-tree index
accepted only exact feature-address parents and rejected a selected-partner
claim whenever no feature had the same address. The observed claims were
entity-scoped, so the wrapper rejected valid canonical input.

This record supports only lossless tree indexing for both exact feature scope
and exact entity scope. It does not promote a use case into semantic support,
infer a missing feature, or claim that every device of this family has these
counts.

## Redaction Boundary

The published record contains no SKI, SHIP ID, device or SPINE address,
endpoint, private network coordinate, certificate material, credential,
session or CSRF value, trust-store byte, raw frame, raw payload, or private
artifact hash. The complete addresses and payloads remain only in the retained
owner-authorized artifact.

## Falsification Criteria

This record is false if the retained artifact shows different topology counts,
if any of the twenty-two claims did not exactly match a retained entity
address, if any matched a retained feature address, or if the Portal failure
was produced before the valid raw snapshot reached the lazy-tree parent
resolver.
