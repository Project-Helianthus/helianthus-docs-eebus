## Supported And Unresolved Claims

The inspected source supports an implementation-level claim only. It does not
establish wire interoperability, a deployed runtime result, or conformance to
SHIP section 12.2.2. The final PR revision, independent review, focused test
execution, and a bounded interoperability run remain open evidence steps.

## Falsification Criteria

This record is falsified by any final reviewed source or focused test that
demonstrates one of the following:

1. With a trusted remote and simultaneous attempts, the lower-key initiator's
   direction is retained, or both directions become active.
2. With the local identity key higher and an outbound attempt initiating, the inbound
   connection reaches `Run`, initializes data processing, or reaches protocol
   activation instead of being rejected.
3. An inbound connection starts data processing before Hub ownership is
   registered.
4. After shutdown or a competing replacement closes an inbound connection
   before `Run`, a later `Run` starts a read or write pump, or terminal close is
   reported more than once.
